## First check in the game

For an existing installation, use `/reload` outside combat. A first installation needs a full game restart. Open `/fm` and confirm v0.11.0, your class artwork, faction label, and slot count. Run `/fm status` to check the loaded addon version and full client build. Confirm ElvUI loads without the party-frame error and existing button sizes and scale remain as configured. Default player and target positions should be higher and farther apart; manually customized positions should remain intact.

For Shaman, find FM Easy with `/fm easy` and place it on a bound bar slot. Against a suitable living enemy, verify that the first press applies Lightning Shield and starts melee, then further presses cast only learned damage steps. Confirm shocks wait for the shared cooldown while swings continue. Target a friendly unit and verify no shield, pet command or attack is attempted. On Priest, verify repeated presses preserve Penance/Mind Flay channels, shielding addresses self and a blocked shield does not prevent later damage attempts. On Paladin, verify Judgement leaves the seal active and Holy Strike uses the next available global action. On Hunter, verify Auto Shot and pet attacks continue while the sequence waits, including the Summon Hawk upgrade when learned.

Check FM Totems before and after learning Call of the Elements. Before learning it, confirm one totem per successful press and an inactivity reset after ten seconds. After learning it, configure the native set and verify one cast drops that set. Confirm no totems or Recall occur while using FM Easy. Test Recall only on its separate button. Refresh learned spells during combat and verify owned macro text changes only after combat ends. These client checks are pending; automated tests cannot certify them.

With the FM window and tools panel closed, open the combined backpack normally. Drag its title without a command. Confirm the complete window moves and its Sort button remains attached. Right-click to lock, close/reopen, and reload to check the saved position and lock. Right-click again to permit dragging. Repeat with a BlizzMove-supported window such as the character panel. Use Move windows in FM for ElvUI bars and frames. Leave combat before changing window positions.

Open `/fm training` and confirm the provider list fits, scrolls and updates after training. Close the tab, then use `/wt` to verify the original window still works. Check `/macro` for FM AutoOpen and FM AutoPrep with learned abilities only. Training a new supported spell should update the owned sequence without another install command.

Open `/ec` and confirm the current FM LG profile. On the lower LG display, check button labels, bag header access, buff and weapon-enchant visibility, pet/stance/totem bars, and group-frame positions. Test a healer profile and Feral Tank when available. Record frame time and memory in the same scene before and after enabling the added addons. The 375 mock checks do not establish live taint safety, native mouse routing, legibility or FPS impact.

For bag tools, open `/fm bags`. Move two individual bags, lock them, close/reopen and reload. Switch to combined bags and test its separate position. Resize the window or change UI scale, then verify the bags remain accessible. Reset and hide the tools to confirm native placement returns. Check combat start while dragging. Click Sort with an empty cursor and unlocked items; verify actual item order and conservation of items. Test an excluded bag, a special bag and the reverse direction. Opening bags and looting must leave the current order alone. No native bag execution or rendering is claimed by the mock results.

Open `/fm coach`. Browse the nine classes and three trees each. Choose a plan for your character and compare the listed ranks with the game's talent window. Check pending talent edits, a changed build and points outside the plan. Confirm that the first suggested point's availability matches the client and that combat suspends personal comparisons. Some plans require a respec; do not treat their first point as the next step of an earlier plan.
Show the fixed reference bar, check learned abilities and default-bar keys, move it, lock it and reload. Confirm it remains a fixed reference in combat and casts nothing. Previewing a different class must not change the active bar's class. Check `/fm coach status`; an available native provider still must not be presented as connected. Measure frame time and addon memory with the Coach closed, open and with its bar enabled in the same scene. These native checks remain outstanding.

For the workshop, open `/fm sequences`. Review a learned class starter, save the draft, and confirm no macro appeared until clicking Install. Drag the created sequence to a bar, press each step, then try Alt reset and an unavailable step. Verify the sequence waits as described. Check a modifier draft with no modifier, Shift and Ctrl. Test channel and caster-form guards where applicable.

Save a build before changing the sequence. Load a history entry and confirm the installed macro stays unchanged until Install. Export/import a sequence and build; inspect previews and scroll the share box. Apply a reviewed build outside combat. Change a macro by hand and confirm workshop updates preserve it. Reload and verify saved drafts, builds and history. Compare frame time and addon memory with the window closed and open in the same scene. Record actual client results separately.

1. Learn a new supported skill while a character macro slot is free. Confirm that its starter attack macro appears without running an install command. An optional skill needs a saved selection in the library first.
2. Drag the FM macro from the character tab of `/macro` onto a bar once. Existing plain spell buttons remain plain spell buttons until you replace them.
3. Test a damage button on a living selected enemy. For melee, check that swings start even when the ability is on cooldown. For Hunter shots, check that Auto Shot starts and repeat presses do not turn it off.
4. Test hostile mouseover and Shift-focus separately. Utility buttons should use the intended unit without starting a new attack at a different selected enemy.
5. Queue an assignment during combat. Confirm its previous target remains active until combat ends.
6. Check a personal edit is preserved, then reload and check saved choices. Test a second class and faction when available.
7. If learned, test ShiftingPower in Cat Form and outside it, or SpearStrike in Battle Stance and another stance. Check that the guarded button acts only in its required form or stance. PetAggressive should appear only after selecting it in the library.
8. For a Priest who learned Penance, select PenanceHeal and PenanceHarm. Test friendly mouseover, Alt-self, hostile target and Shift-focus. Repeated presses during a channel should leave it running. Test an assigned teammate who is present, dead and absent.
9. For a Druid, test Prowl and Dash in caster, Bear and Cat forms. Prowl should remain active after repeated presses and should not be attempted in combat. Test Shifting Power at full energy and below full energy; the game decides whether it can cast.
10. Test the separate Wand button with repeated presses. The beta `!Shoot` bug remains unresolved by this addon; report observed behavior without treating the mock result as game proof.

A rankless spell name normally stays the same when learning a higher rank. The game chooses the learned rank. An unchanged macro body alone does not show that an update failed.

No live spell success, boss advance-warning accuracy, or complete private Discord review is claimed by these results. Earlier testing of version 0.3.x is historical evidence only.
